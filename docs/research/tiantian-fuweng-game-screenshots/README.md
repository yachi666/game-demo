## 游戏简介

《天天富翁》是一款由腾讯移动游戏平台独家代理运营的全民互动休闲手游，由韩国N2PLAY工作室研发。游戏类似于传统大富翁、强手棋游戏玩法，操作更简单，地图更精致，以清新柔亮的Q版风格呈现萌趣搞笑游戏画面。

**注意**: 国服天天富翁已于2019年停服，目前中文版只有台服（LINE 旅游大亨）。

### 核心玩法

- 掷骰子移动
- 购买地产建造建筑
- 收取过路费
- 角色养成系统
- 多样骰子系统
- 独占胜利规则

### 地图类型

游戏包含多种主题地图：
- 世界地图
- 宇宙地图
- 中国地图
- 探险地图
- 游乐园地图
- 神之手地图
- 魔法庭院
- 水上都市
- 糖果店
- 果园地图
- 等多种特色地图

### 角色系统

角色卡片从C级到S+级，每个角色拥有不同的能力值：
- 控骰能力
- 建设费用折扣
- 收购费用折扣
- 特殊技能
